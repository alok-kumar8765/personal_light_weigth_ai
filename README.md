📖 About the Project

The Personal AI Assistant is a Python-based web application that uses an OpenAI language model to generate conversational responses to user messages.

The application is developed with Streamlit, which makes it possible to build an interactive web interface using Python without requiring extensive HTML, CSS, or JavaScript knowledge.

Users can enter an API key, type a message, and receive a response from the AI assistant directly in their browser.

🎯 Project Objectives
Build a simple AI chatbot using Python.
Integrate the OpenAI API into a web application.
Create an interactive interface with Streamlit.
Maintain conversation history during an active session.
Understand API integration, session state, and exception handling.
Provide a foundation for developing a more advanced personal AI assistant.

✨ Features
1. AI-Powered Conversations

Ask questions, brainstorm ideas, and receive responses generated by an OpenAI language model.

2. Interactive Chat Interface

Use Streamlit's chat components to send messages and display assistant responses in a conversational format.

3. Conversation History

Messages are stored in Streamlit session state so the conversation can continue across normal application reruns within the same session.

4. API Key Input

Enter an OpenAI API key through a password-style input field in the sidebar.

5. Real-Time Response Generation

The application sends messages to the OpenAI API and displays the returned response.

6. Loading Indicator

A spinner indicates that the assistant is processing a request.

7. Error Handling

API exceptions can be caught and displayed to help diagnose problems such as invalid credentials, connectivity issues, or unavailable models.

8. Simple and Extendable Architecture

The project can be extended with features such as file uploads, persistent chat history, voice interaction, and document summarization.

⚙️ Installation and Setup Guide

Follow these steps to install and run the project on Windows.

Step 1: Open the Project Folder

Open Command Prompt and navigate to your project directory.

Example:

cd /d "C:\Users\AIT\Desktop\Social Media\project\personal AI Assistant"


Replace the example path with your own project path if necessary.

Step 2: Create a Virtual Environment

A virtual environment keeps the project's Python dependencies separate from other projects.

py -m venv .venv

Step 3: Activate the Virtual Environment

For Windows Command Prompt:

.venv\Scripts\activate


For Windows PowerShell:

.\.venv\Scripts\Activate.ps1


If activation succeeds, your terminal will generally show (.venv) before the command prompt.

If PowerShell blocks activation, you can use Command Prompt or invoke the environment's Python executable directly.

Step 4: Upgrade pip
python -m pip install --upgrade pip

Step 5: Install the Dependencies

You can install the required packages directly:

python -m pip install streamlit openai


Alternatively, create a requirements.txt file containing:

streamlit
openai


Then install the dependencies using:

python -m pip install -r requirements.txt


For reproducible deployments, pin and test specific dependency versions before publishing the project.

Step 6: Configure the OpenAI API Key

The application needs a valid API key to communicate with OpenAI.

You can create or manage your key here:

https://platform.openai.com/api-keys

There are two configuration options.

Option A: Enter the key in the application

If your app.py uses a sidebar password input, start the application and enter your key there.

Option B: Use Streamlit secrets

Create the following file:

.streamlit/secrets.toml

Add:

OPENAI_API_KEY = "your-openai-api-key"


Keep this file private. Add .streamlit/secrets.toml to .gitignore so it is not committed to Git.

If you use this option, update the application to read the secret instead of requiring manual entry.

For example:

api_key = st.secrets.get("OPENAI_API_KEY", "")


Use the same approach consistently; avoid accidentally overriding a configured secret with an empty input value.

Step 7: Run the Application

Start the application with:

python -m streamlit run app.py


This command is recommended because it invokes Streamlit through the active Python environment.

Streamlit will normally display a local URL such as:

http://localhost:8501


Open the displayed URL in your browser if it does not open automatically.

🔄 How It Works

The application follows a straightforward workflow:

Initialize Streamlit: Configure the page and display the interface.
Obtain credentials: Read the API key from the configured input or secret source.
Create the client: Initialize the OpenAI Python client.
Initialize session state: Create a message list when the conversation starts.
Display previous messages: Render stored user and assistant messages.
Receive user input: Read the submitted message from the chat input.
Send the request: Pass the conversation to the selected OpenAI model.
Display the response: Show the generated answer in the chat interface.
Update history: Store the assistant response for subsequent interactions.

⚠️ Limitations

The current implementation is a starting point rather than a complete production-ready assistant.

1. No Persistent Conversation Storage

Messages stored in st.session_state are not a permanent database. Chat history can be lost when the session resets or the application is restarted.

2. API Dependency

The application depends on the availability of the OpenAI API, valid credentials, and access to the selected model.

3. Usage Costs

API requests may incur charges depending on the model, token usage, and current pricing.

4. Limited File Support

The basic version does not automatically read PDFs, Word documents, images, or other uploaded files.

5. No Built-In Web Search

The basic application does not independently search the internet for current information.

6. No Voice Features

Voice input and speech output are not included in the basic implementation.

7. No User Authentication

The initial version does not include user accounts, role-based access, or a multi-user management system.

8. Limited Production Security

A public deployment requires additional security controls, including secure API key management, usage limits, input validation, and appropriate error handling.

9. Model Accuracy

AI responses can contain factual errors. Important information should be verified using reliable sources.

🛠️ Troubleshooting
Problem 1: streamlit Is Not Recognized

Error:

'streamlit' is not recognized as an internal or external command


Solution:

Install Streamlit in the active Python environment:

py -m pip install streamlit


Then launch the app using:

py -m streamlit run app.py

Problem 2: Missing OpenAI Credentials

Error:

OpenAIError: Missing credentials


Solution:

Run the application through Streamlit.
Enter a valid API key if the sidebar input is enabled.
If using Streamlit secrets, verify the key is present in .streamlit/secrets.toml.
Ensure the code passes the key to OpenAI(api_key=api_key).
Problem 3: Invalid API Key

Possible cause: The key is incorrect, revoked, or copied incompletely.

Solution: Verify the key in your OpenAI API account and replace it if necessary. Never print the key in logs or share it in screenshots.

Problem 4: Model Not Found or Access Denied

Possible cause: The requested model identifier is invalid or unavailable to your API project.

Solution: Use a currently supported model that your account can access. For example, gpt-4o-mini may be suitable when available to your account.

Problem 5: API Quota or Billing Error

Possible cause: Your project has insufficient available quota, a billing issue, or a usage limit.

Solution: Check your API usage and billing configuration in the OpenAI platform.

Problem 6: Port Already in Use

Solution: Run the app on another port:

python -m streamlit run app.py --server.port 8502


Then open:

http://localhost:8502

Problem 7: ScriptRunContext Warnings

Possible cause: The Streamlit application is being executed as a normal Python script.

Solution: Use:

python -m streamlit run app.py


rather than python app.py.
